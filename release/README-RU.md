# WeaponFlow

До трёх наборов настроек для каждого оружия. Набор 1 применяется при взятии
оружия, остальные переключаются одной кнопкой — даже при прицеливании и стрельбе.
Отдельный HUD показывает выбранную настройку иконкой, текстом или обоими способами.

## Быстрый старт

**R — ваша кнопка карточки оружия.** Если она переназначена, используйте свою.
Дождитесь открытия карточки и продолжайте держать кнопку.

| Действие | Кнопки по умолчанию |
| --- | --- |
| Сохранить набор | R → P → 1, 2 или 3 |
| Очистить все наборы этого оружия | R + двойное P за 0,3 секунды |
| Переключить набор | Назначенная кнопка без R |
| Открыть подсказку HUD | R + H; следующие H меняют отображаемую настройку |
| Выбрать иконку, текст или оба | F10 при открытой подсказке HUD и удержании R |
| Передвинуть индикатор | Стрелки при открытой подсказке HUD и удержании R |

Кнопку свапа назначьте в **Настройки → Мышь и клавиатура → MODS → WeaponFlow**.
P можно отпустить: номера сохраняют наборы, пока держится R. Подсказки показывают
действующие назначения. Очистка оставляет текущие режимы оружия и общий фонарик
без изменения. Кнопки меню и типы нажатия можно переназначить. Очистка использует
двойное нажатие текущей кнопки меню наборов; отдельного назначения у неё нет.

## Установка

Импортируйте **WeaponFlow-v1.9.9.zip** и используйте его с **Bingus Shared Loader v17** и **Mod Bindings Menu v2.1**.
Кнопки работают после запуска. В **Настройки → Мышь и клавиатура → MODS → WeaponFlow**
можно изменить назначения.
Замените предыдущий основной WeaponFlow; прежние Trial, Probe и полные Diagnostics
одновременно с ним не нужны. После изменения выбранных модов выполните Purge/Deploy.

В Arsenal включается одна опция **WeaponFlow**, объединяющая наборы и HUD.
Формат индикатора выбирается прямо в игре: при открытой подсказке HUD нажимайте
**F10**. Иконка, текст и иконка с текстом перечислены в панели; действующий
вариант выделен жёлтым. Выбор сохраняется для профиля.

Дополнительный **Weapon-Defaults-Diagnostics-Addon-v1.0.0.zip** включает подробные
журналы совместно с основным модом. Он остался прежним; обновлять его не требуется.

## Настройка кнопок

Требуется **[Mod Bindings Menu v2.1](https://www.nexusmods.com/helldivers2/mods/16478)**.
Откройте **Настройки → Мышь и клавиатура → MODS → WeaponFlow**.

| Назначение | Что делает |
| --- | --- |
| Меню наборов | Открывает подсказку наборов и разрешает сохранение цифрами |
| Переключение наборов | Переключает непустые наборы по кругу |
| Меню HUD | Открывает подсказку индикатора; следующие активации меняют настройку |
| Сбросить мод | Сбрасывает настройки WeaponFlow, включая свою кнопку |

Выберите кнопку и тип её активации: Press, Release, Hold, LongPress, Tap,
DoubleTap, LongHold или LongRelease. Нажатия обрабатывает игра. Удержание
выполняет команду один раз. Пустое назначение отключает команду.
Меню наборов и HUD по умолчанию открываются **P/H, обычное нажатие**.
**Переключение наборов и сброс изначально не назначены.** Кнопка свапа назначается только в MODS.

WeaponFlow использует назначения, которые принимает Mod Bindings Menu v2.1
и обрабатывает игра. Обычные игровые действия не блокируются.
Подсказки показывают действующие назначения и типы нажатия.

**Стартовые наборы уже включены.** Новый профиль получает готовые наборы;
любой из них можно заменить или очистить.

**Reset mod** возвращает стартовые наборы, сбрасывает общий фонарик, HUD
и назначения WeaponFlow, включая собственную кнопку Reset, затем возвращает начальные P/H.
Перед сбросом создаётся резервная копия. Управление игры и других модов сохраняется.

Назначения сохраняет игра; WeaponFlow читает её действующие клавиши.
При обновлении прежние кнопки, наборы и настройки HUD сохраняются.

## Как работают наборы

- Настройки хранятся для типа оружия и профиля игрока. Они действуют для любого
  экземпляра, включая оружие другого игрока, и сохраняются между миссиями.
- Набор 1 применяется при настоящем взятии или смене оружия. Стим и бросок гранаты
  не сбрасывают вручную выбранные режимы оставшегося в инвентаре оружия.
- Ручные изменения сохраняются до следующего взятия или переключения набора.
  Пустые наборы пропускаются.
- При сохранении обновляются доступные настройки. Отсутствующий модуль не стирает
  ранее сохранённый прицел; совместимый экземпляр сможет его использовать.
- Если есть одна настройка кроме фонарика и два её значения, доступны наборы 1/2.
  Сохранение одного заполняет второй противоположным значением. При трёх значениях
  сохранение удаляет другие наборы с тем же значением, сохраняя отличающиеся.

**Фонарик — общая настройка.** Выберите Auto, On или Off в игре, и последнее значение
будет применяться при взятии любого оружия с фонариком. Оно не входит в наборы,
не очищается вместе с ними и не показывается индикатором. Работает с Weapon presets.

## HUD

В обеих подсказках рядом с удерживаемой кнопкой карточки появляется последняя
нажатая кнопка. Если смена наборов не назначена, подсказка наборов показывает
**«Выставите в настройках!»**.

Первое R + H открывает подсказку. Следующие нажатия выбирают доступные на текущем
экземпляре настройки или Hide. Отсутствующие модули и фонарик пропускаются.
При открытой подсказке HUD **F10** переключает формат: **иконка / текст /
иконка и текст**. Все варианты видны в панели, выбранный выделен жёлтым.
Формат общий для профиля; отображаемая настройка сохраняется отдельно для каждого
оружия. В меню наборов и после закрытия подсказки F10 ничего не меняет.
Стрелки перемещают только отдельный индикатор: удержание постепенно ускоряет движение.
Подсказка остаётся на месте и закрывается при отпускании кнопки карточки.

## Язык и обмен наборами

Включены **все 14 языков текста игры**: английский, русский, французский,
немецкий, итальянский, польский, японский, корейский; испанский Испании и Латинской
Америки, португальский Португалии и Бразилии; упрощённый и традиционный китайский.
Названия режимов оружия взяты из соответствующих переводов игры.

Режим **Как в игре** следует языку текста игры; если перевода нет, используется
английский. При открытой любой подсказке **F9** переключает **Как в игре**,
английский и остальные доступные языки по кругу. Текст меняется сразу,
включая названия назначений WeaponFlow в MODS. Выбор языка сохраняется.

При открытой **подсказке наборов**:

- **C** копирует все наборы аккаунта в буфер обмена.
- **V** вставляет наборы из буфера, **полностью заменяя все наборы аккаунта**.

Некорректный текст игнорируется без изменений. Общий фонарик и настройки HUD
не входят в переносимые наборы. F9, C и V нельзя переназначить; они работают
только при открытых соответствующих подсказках.

## Файлы и журналы

В папке WeaponDefaults:

- `<SteamID64>.ini` — наборы и общий фонарик.
- `<SteamID64>-HUD.ini` — отображаемые настройки и позиция индикатора.
- `<SteamID64>-Menu.ini` — язык и отметки разовой установки исходных клавиш.
- `Backups` — резервные копии.

Журнал: `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\WeaponDefaults.log`.
Диагностическое дополнение включает более подробную запись в той же папке.
